# ストアを使わずアプリとして利用する

[現行版](https://appi0216.github.io/pokemon-unite-draft/)と[Draft 02](https://appi0216.github.io/pokemon-unite-draft/v2/)は、それぞれ別のアイコンで追加できるPWAです。アカウント作成やストアへのアクセスは不要です。

| 端末・ブラウザー                     | 追加方法                                                                                                                                   |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| iPhone・iPad                         | Safariで開き、共有 →「ホーム画面に追加」。「ウェブアプリとして開く」がある場合はオンにする                                                 |
| Android                              | Chrome等のメニューから「アプリをインストール」または「ホーム画面に追加」。対応環境ではアプリ内の使い方画面にも「アプリを追加」が表示される |
| Mac・Safari                          | macOS 14以降で「ファイル」→「Dockに追加」                                                                                                  |
| Windows・Mac・ChromeOSのChrome／Edge | アドレスバーまたはメニューのインストール操作                                                                                               |
| インストールに対応しないブラウザー   | 同じURLをブラウザーで利用する                                                                                                              |

Androidの追加方法・名称・アイコンの扱いはブラウザーと端末によって異なります。Safariのホーム画面／Dock追加はブラウザー側の操作が必要です。Webサイトから自動で端末へインストールすることはありません。

## 保存・オフライン・更新

初回はオンラインで開き、使い方画面で「オフラインで利用できます」の表示を確認してください。両版の画面、102枠の画像、必要なファイルを保存してから利用可能と表示します。保存できなかった場合は「再試行」が表示されます。

ドラフトは利用したブラウザー／アプリ内に保存されます。別端末との同期はなく、Safariと追加したWebアプリなど保存領域が分かれる環境では自動移行されません。サイトデータの削除やOSによる容量整理で、保存データとオフライン用データが消える場合があります。必要な記録は現行版のバックアップ、または新規版の記録保存を利用してください。

更新版は進行中の画面を強制再読み込みしません。更新のお知らせが出たら、両版のタブとアプリウインドウをすべて閉じて開き直してください。ドラフトの保存は維持されます。

縦横の向きは固定しません。セーフエリア、可変画面高、タッチ操作、文字拡大、動きを減らす設定に対応しています。画面が極端に小さい場合や文字を拡大した場合には、内容を隠さないためスクロールを使用します。

## 確認した範囲

Windows上のChromium 151とWebKit 26.5で、両URLのオフライン再起動、画像、保存復元、更新待機、キャッシュ修復の自動検証に合格しました。Chromiumのインストール要件診断もエラー0件でした。端末判定に応じた説明、インストールイベントの受付・取消・完了は模擬テストに合格しました。

物理的なiPhone・iPad・Android・Macへのインストール、ホーム画面のOS表示、VoiceOver、実機のソフトウェアキーボードは未検証です。古いブラウザーや組み込みブラウザーを含む全端末の動作保証ではありません。最新のSafari／Chrome／Edgeを利用してください。
