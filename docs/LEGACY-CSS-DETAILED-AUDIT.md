# 旧CSS詳細監査・整理結果（2026-10-18）

## 113組の判定

前回抽出した113組すべてについて、適用条件、セレクター、宣言順、プロパティ、値、importantを照合した。

- 13組：後方に同条件・同値の宣言が存在する17宣言を削除。
- 100組：異なる値または追加プロパティを持つため保持。単なる同名セレクターを理由に合体しない。短縮指定や間にあるルール、ブラウザーの値対応が絡むため、元の順序を維持する。
- 各宣言の削除先／保持理由：[判定一覧](LEGACY-CSS-DECISIONS.json)。

これは113組をすべて1ルールにまとめたという意味ではなく、全候補について削除または保持の判定を付けたもの。

## 未使用指定

現行のTS・TSX・データ、動的className、DOM生成コードを確認した。旧ホーム、旧選択情報、削除済みバックアップ等の生成されない64クラスを抽出。そのクラスを必須とする546本のセレクター分岐を削除した。複数セレクターのルールは使用中の分岐だけを残した。

- 動的なcompact-view-roster/purple/orangeは保持。
- :not()等の関数型疑似クラスを含む227ルールは意味を変える危険があるため保持。未使用と断定しない。
- 実行時に一度も一致しないセレクターでも、hover/focus、強制カラー、印刷、保存失敗等の条件で必要になり得るため、それだけを根拠に削除しない。
- 削除・保持の根拠：[未使用判定一覧](LEGACY-CSS-UNUSED-DECISIONS.json)。

## 検証範囲と限界

最終CSSで320×568、667×375、1280×800、Chromium/WebKitの画面遷移を実行し、各状態のセレクター一致も収集。準備、設定、先攻、検索、フィルター、リセット、巻戻し、試合完了、履歴、次試合、シリーズ終了、再開、上書きの160状態を対象とした。明暗・200%文字の条件を含む。別途ホーム4サイズ、履歴3サイズ、上下固定領域5サイズを両ブラウザーで検証。

有限の試験で将来の全状態や全端末まで未使用を証明することはできない。今回完了したのは、全113候補の判定と、現行コードから生成不能と確認できる旧指定の除去。保持した条件付き指定について「全て不要指定を削除済み」とは扱わない。
