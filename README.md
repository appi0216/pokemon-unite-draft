# UNITE DRAFT

ポケモンユナイトの大会形式ドラフトを、1台で両チーム分操作できる非公式Webシミュレーターです。2026年9月18日に確認した公式掲載データを収録しています。

**[シミュレーターを開く](https://appi0216.github.io/pokemon-unite-draft/)**

## 使い方

1. 準備画面でドラフト形式、制限時間、チーム名を設定して開始します。先攻は各試合の開始時に選択します。
2. ポケモンを選び、画面下のボタンでBANまたはPICKを確定します。BANは各チーム3体を交互に指定し、PICKは先攻1 → 後攻2 → 先攻2 → 後攻2 → 先攻2 → 後攻1の順で進みます。
3. 進行バーから確定済みのターンへ戻れます。BAN／PICKフェーズへの確認後、選んだ位置から進め直せます。直前の操作だけを戻すには「1つ戻す」を使います。
4. 両チームの選出が終わったら、同じチームの枠を2つ選ぶと配置を交換できます。結果はPNG画像で保存できます。

「選択可能のみ」は初期状態でONです。検索欄にフォーカスするには `/`、ポケモン一覧の移動には矢印キー、確定には `Enter`、直前の操作を戻すには `U` を使えます。制限時間を有効にした場合は `P` でタイマーを一時停止・再開できます。

画面幅が狭いときは、ドラフト画面上部の「パープルチーム／ポケモン一覧／オレンジチーム」で表示を切り替えられます。

制限時間は「なし／あり」から選びます。「あり」のときはBANが各15秒、PICKが各ターン20秒です。2体PICKのターンは20秒を共有します。BANは時間切れでスキップし、PICKは時間切れ後も手動で確定できます。

## ドラフト形式

| 形式                 | 次の試合と使用済みポケモンの扱い                                                                                                                               |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 通常ドラフト         | 次の試合を選ぶと、新しいドラフトをすぐに開始します。前の試合の選出は引き継ぎません。                                                                           |
| オールスタードラフト | BO3／BO5／BO7から選べます。過去の試合で両チームがPICKしたポケモンは、以降の試合で両チームともBAN・PICKできません。                                             |
| フィアレスドラフト   | BO3／BO5／BO7から選べます。前の試合で自分のチームがPICKしたポケモンは、次の試合で同じチームがPICKできません。相手チームはBANやPICKをされていなければ選べます。 |

フィアレスのBAN中に「選択可能のみ」をONにすると、相手が過去にPICK済みで再使用できないポケモンも一覧から除きます。これは無意味なBANを避けるための表示フィルターです。オールスターでは、過去にPICKされたポケモンがBAN・PICKの両フェーズで自動的に使用不可になります。どちらの形式も過去のBANは次の試合へ持ち越さず、先攻は試合ごとに選択できます。勝敗の記録・判定は行いません。

進行状況と設定はこのブラウザーに自動保存されます。別の端末・ブラウザーとは同期されず、サイトデータを消すと保存内容も消えます。必要なデータの読み込みが完了して「オフライン利用可能」と表示された後は、通信なしでも利用できます。

## 追加機能

- 準備画面の「プリセット・大会制限・バックアップ」でチーム名とトレーナー5人を保存し、左右どちらにも適用できます。同名の保存は上書きします。
- 大会の使用不可ポケモンを指定すると、新しく開始するドラフトのBAN・PICK候補から除外します。
- 「1つ戻す」の取り消しは、隣の「1つ進む」またはYキーで復元できます。新しい確定・リセット・試合移行で復元候補は破棄されます。再読み込み後には持ち越しません。
- 試合履歴から各試合を画像保存できます。オールスターとフィアレスでは、完了した全試合を1枚にまとめる保存にも対応しています。
- 新しい試合はチーム名・トレーナー名も記録します。名前未記録の旧履歴のみ、現在の設定で表示します。
- 進行状況、履歴、保存済み設定、チームプリセットをJSONでバックアップできます。読み込みは検証と確認後に現在の内容を置き換えます。準備画面の未確定の変更は含みません。

結果画像を開く操作は「結果画像を確認」、ダウンロードする操作は「画像を保存」です。

## ローカルで起動

Node.js 20.16以上とnpmが必要です。

```sh
npm install
npm run dev
```

公開版と同じ構成を確認する場合は、`npm run build` と `npm run preview` を実行し、`http://127.0.0.1:4173/pokemon-unite-draft/` を開きます。開発サーバーではService Workerを登録しません。

```sh
npm test
npm run build
npm run test:offline
```

更新・過去の版への戻し方は[運用手順](docs/MAINTENANCE.md)を参照してください。`main`への更新はGitHub Actionsでテスト・ビルド・公開されます。

## 収録範囲と設計

大会形式の3BANドラフトを練習するためのアプリです。投票式BAN、バトル準備画面や勝敗判定は含みません。ミュウツーX／Yと通常／メガの別ライセンスは独立して選択できます。ウーラオスの2形態、ハッサム／ストライクはそれぞれ1ライセンスとして扱います。

React・TypeScript・Viteによる静的サイトで、サーバーやアカウントは不要です。ドラフトの進行ルールはブラウザーAPIに依存しない[`src/domain/draft.ts`](src/domain/draft.ts)に分離しています。将来のモバイル・デスクトップアプリ化でもルールを再利用できる構成ですが、ネイティブアプリやストア配布物はまだありません。

ポケモン画像は同一サイト内のWebPを使用します。透過画像内の描画範囲に合わせて大きさと中心をそろえ、最初の画像を優先読み込みし、残りは遅延読み込みと非同期デコードで表示します。本番ビルドではService Workerを生成してオフライン利用に備えます。PWAに対応するブラウザーではホーム画面への追加も可能です。
