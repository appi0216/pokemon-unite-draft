プレイアブル一覧であり、別地域専用版の独自内容を含む確認ではない。

## 画像と再生成

公式PNGを既存と同じ208×208pxの透過WebP（quality 78）に変換。
各画像の不透明部分を測定して、ポートレート枠に対する最大寸法84%・中央配置に
正規化する既存処理を適用した。画像一覧はオフライン用manifestにも登録する。

将来の更新時は、まず公式一覧と参戦告知を確認し、その確認日を明示して実行する。

```powershell
node scripts/prepare-assets.mjs 2026-10-15
node --test tests/roster.test.mjs
```

スクリプトは現在の公式一覧を取得する。日付引数は確認日を記録するためのもので、
過去日の一覧を取得する機能ではない。古い `roster-source.html` は使用しない。
新しい参戦があった場合は、この記録とテストの基準日・枠数も更新する。
