対象リビジョン、対応ブラウザー・環境、到達可能なDOMと保存データ、動的クラス生成を固定する。その範囲で、対象のセレクターと環境条件が同時に成立不能、または削除前後のカスケード結果が全対象状態で同値であることを示す。スクリーンショット比較や有限回の操作試験だけを全称証明と呼ばない。
