# UNITE DRAFT

ポケモンユナイトの大会形式ドラフトを、1台で両チーム分操作できる非公式Webシミュレーターです。2026年9月18日に確認した公式掲載データを収録しています。

**[シミュレーターを開く](https://appi0216.github.io/pokemon-unite-draft/)**

## 使い方

1. 準備画面でドラフト形式、先攻チーム、制限時間、チーム名を設定して開始します。先攻の初期値は左側です。
2. ポケモンを選び、画面下のボタンでBANまたはPICKを確定します。BANは各チーム3体を交互に指定し、PICKは先攻1 → 後攻2 → 先攻2 → 後攻2 → 先攻2 → 後攻1の順で進みます。
3. 進行バーから確定済みのターンへ戻れます。取り消される件数を確認してから実行します。直前の操作だけを戻すには「1つ戻す」を使います。
4. 両チームの選出が終わったら、同じチームの枠を2つ選ぶと配置を交換できます。結果はPNG画像で保存できます。

「選択可能のみ」は初期状態でONです。検索欄にフォーカスするには `/`、ポケモン一覧の移動には矢印キー、確定には `Enter`、直前の操作を戻すには `U` を使えます。制限時間を有効にした場合は `P` でタイマーを一時停止・再開できます。

画面幅が狭いときは、ドラフト画面上部の「パープルチーム／ポケモン一覧／オレンジチーム」で表示を切り替えられます。選択中の候補は一覧上部と確定ボタンの上に表示されます。

制限時間は「なし／あり」から選びます。「あり」のときはBANが各15秒、PICKが各ターン20秒です。2体PICKのターンは20秒を共有します。時間切れ後も自動選択はせず、手動で確定できます。

## ドラフト形式

| 形式                 | 次の試合と使用済みポケモンの扱い                                                                                                                                                                                                                                                     |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 通常ドラフト         | 次の試合を選ぶと、新しいドラフトをすぐに開始します。前の試合の選出は引き継ぎません。                                                                                                                                                                                                 |
| オールスタードラフト | BO3／BO5／BO7から選べます。前の試合で**自分のチームがPICKしたポケモン**は、次の試合で同じチームがPICKできません。相手チームは、現在の試合でBANやPICKをされていなければ選べます。先攻は試合ごとに交代し、過去の選出をチーム別に表示します。最終試合のドラフト後は準備画面へ戻れます。 |

オールスターのBAN中に「選択可能のみ」をONにすると、相手が過去にPICK済みで再使用できないポケモンも一覧から除きます。これは無意味なBANを避けるための**表示フィルター**で、BAN自体のルールを変更するものではありません。過去のBANは次の試合へ持ち越しません。勝敗の記録・判定は行いません。

進行状況と設定はこのブラウザーに自動保存されます。別の端末・ブラウザーとは同期されず、サイトデータを消すと保存内容も消えます。必要なデータの読み込みが完了して「オフライン利用可能」と表示された後は、通信なしでも利用できます。

## ローカルで起動

Node.js 20.16以上とnpmが必要です。

```sh
npm install
npm run dev
```

公開版と同じ構成を確認する場合は、`npm run build` と `npm run preview` を実行し、`http://127.0.0.1:4173/pokemon-unite-draft/` を開きます。開発サーバーではService Workerを登録しません。

```sh
npm test
npm run build
npm run test:offline
```

更新・過去の版への戻し方は[運用手順](docs/MAINTENANCE.md)を参照してください。`main`への更新はGitHub Actionsでテスト・ビルド・公開されます。

## 収録範囲と設計

大会形式の3BANドラフトを練習するためのアプリです。大会固有の禁止リスト、投票式BAN、バトル準備画面や勝敗判定は含みません。ミュウツーX／Yと通常／メガの別ライセンスは独立して選択できます。ウーラオスの2形態、ハッサム／ストライクはそれぞれ1ライセンスとして扱います。

React・TypeScript・Viteによる静的サイトで、サーバーやアカウントは不要です。ドラフトの進行ルールはブラウザーAPIに依存しない[`src/domain/draft.ts`](src/domain/draft.ts)に分離しています。将来のモバイル・デスクトップアプリ化でもルールを再利用できる構成ですが、ネイティブアプリやストア配布物はまだありません。

ポケモン画像は同一サイト内のWebPを使用します。透過画像内の描画範囲に合わせて大きさと中心をそろえ、最初の画像を優先読み込みし、残りは遅延読み込みと非同期デコードで表示します。本番ビルドではService Workerを生成してオフライン利用に備えます。PWAに対応するブラウザーではホーム画面への追加も可能です。
