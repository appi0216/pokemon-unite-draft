# UNITE DRAFT

2026年9月18日時点の公式掲載ポケモンを収録した、ポケモンユナイトの大会形式ドラフト練習Webアプリです。1台の端末で両チームを操作します。

## 起動

Node.js 20.16以上、npmを使用します。

```sh
npm install
npm run dev
```

本番と同じオフライン対応を確認する場合:

```sh
npm run build
npm run preview
```

プレビューは http://127.0.0.1:4173/ 。開発画面ではService Workerを登録しません。

## 操作

- 「選択可能のみ」は初期状態でONです。
- オールスターは準備画面でBO3／BO5を選択できます。勝敗判定は行わず、第3／5試合のドラフト完了で次の試合を終了し、「準備画面へ戻る」を表示します。最終試合でも画像保存は利用可能です。
- ポケモンをクリックして、画面下の確定ボタンでBAN／PICKを進めます。
- BANは先攻・後攻が交互に3体ずつ。PICKは先攻1 → 後攻2 → 先攻2 → 後攻2 → 先攻2 → 後攻1です。
- BANとPICKの確定済みポケモンは両チームで選択不可になります。BANのスキップも可能です。
- 「1つ戻す」で直前の選択を戻せます。
- 全選出後、同じチームの枠を2つ押すと交換できます。「結果を画像で保存」は両チームのBAN・PICKを1600×1180のPNG画像としてプレビューし、保存できます。
- 初回のホームでドラフト形式、制限時間、先攻、チーム名を選びます。先攻は左側が初期値です。2回目以降は保存中のドラフトへ直接戻ります。ヘッダーの「ホーム」からいつでも設定し直せます。
- 練習タイマーはドラフト開始と同時に動作し、途中再開時は停止状態です。公式の制限時間を断定せず、制限なし／20／30／45／60秒から選択できます。2体PICKのターンは時間を共有します。時間切れで自動選択しません。
- オールスタードラフトでは、前の試合までの両チームのPICKを次の試合のBAN／PICKから除外します。BANは持ち越しません。「次の試合」はホームを挟まず開始し、先攻を交代します。タイマーの設定を引き継ぎ、過去の選出をチーム別・試合別に両端へ表示します。小画面では各チームの下へ配置し、履歴内をスクロールできます。
- 通常ドラフトの「次の試合」は、設定と先攻を保持して新しいドラフトを始めます。試合番号と過去の選出は引き継ぎません。
- 旧バージョンの保存データは使用禁止を維持します。旧データにはチーム情報がないため、過去の選出はチーム不明として区別します。
- 進行はこのブラウザーのlocalStorageへ自動保存します。別端末とは同期しません。
- 「オフライン利用可能」の表示後、アプリ本体と全99画像を通信なしで利用できます。ブラウザーのサイトデータを消去すると保存も削除されます。

## 収録内容・画面の範囲

モルペコまで99ライセンス。未掲載の参戦予告ポケモンや大会固有の禁止リストは自動適用しません。

大会モードの3BAN形式を再現しています。通常カスタム／ランクマッチの投票式BANではありません。公式画面の中央グリッド・左右5枠・BAN枠・紫／オレンジ配色を参照しています。プレイヤーアバター、ゲーム内背景、バトル準備・もちもの・ルート選択画面は含みません。公式クライアントそのものの複製ではなく、ドラフトに集中した非公式シミュレーターです。

ミュウツーX／Yと通常／メガの別ライセンスは独立して選択できます。ウーラオスの2形態、ハッサム／ストライクはそれぞれ1ライセンスとして扱います。

## 画像の統一とレイアウト

- 透過画像内の描画範囲を計測し、全99体の大きさと中心を共通の基準で表示します。画像ファイルは増やさず、位置と倍率の小さなデータだけを使用します。
- 選出枠は画像の元寸法に依存しない固定の領域へ配置。操作ボタンと進行順は独立した領域に配置し、PICK後の重なりを防ぎます。

## 軽量化

- 公式の透過PNGを208×208 WebPへ変換。99枚合計20,957,839バイト → 1,007,416バイト（約95.2%削減）。
- 最初の24枚を優先読み込み、以降はlazy loadingと非同期デコード。寸法を予約し、画像読み込みによるレイアウト移動を防ぎます。
- 画像は同一サイトに同梱し、表示時に公式サイトへアクセスしません。Webフォントも使いません。
- 本番ビルド後にService Workerを生成。起動後、アプリ本体と全画像をキャッシュします。オフライン対応のため、初回はバックグラウンドで残りの画像も取得します。
- ファイル名にハッシュを含むJS／CSSとバージョン別キャッシュを使用します。

## 設計とアプリ化

React + TypeScript + Viteの静的アプリです。サーバーやアカウントは不要です。

| 配置                         | 役割                                                                          |
| ---------------------------- | ----------------------------------------------------------------------------- |
| `src/domain/draft.ts`        | UI・ブラウザーAPIに依存しないドラフト状態遷移。将来のアプリでも再利用できます |
| `src/data/`                  | 2026-09-18のロスター、役割、出典、画像サイズ実績                              |
| `src/App.tsx`                | 操作画面、タイマー、ブラウザー保存・出力                                      |
| `src/design.css`             | PC3列／スマートフォン2チーム＋一覧のレスポンシブレイアウト                    |
| `public/pokemon/`            | 圧縮済みローカル画像                                                          |
| `scripts/build-offline.mjs`  | ビルド済みファイルに対応したService Worker生成                                |
| `scripts/prepare-assets.mjs` | 保存済み公式HTMLを元にした画像圧縮とデータ生成                                |
| `tests/`                     | 進行順、禁止制約、交換、オールスター、保存復元、オフラインキャッシュの検証    |

現時点でPWA用manifestとアイコンを用意しています。iPhoneはSafariの共有メニュー →「ホーム画面に追加」、対応するAndroid／PCブラウザーではインストールできます。HTTPSまたはlocalhostで使用してください。

将来のiOS／AndroidアプリはCapacitorなどのWebViewコンテナーへ`dist`を組み込み、保存・ファイル出力を端末用アダプターに差し替える構成を想定しています。PCアプリはTauriなどの同様のラッパーで同じUIとルールを再利用できます。ネイティブプロジェクト、署名、ストア配布物はまだ作成していません。
